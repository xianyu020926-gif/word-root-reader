# 0.14.0：让单词本可查、可理解、可巩固

日期：2026-09-08

本轮保持词汇主线、原文不改写、自主选词和低干扰界面。

## 本轮变化

- 单词本搜索已保存的词形、意思、词根；点结构标签按相同构词成分查已有词，无新增模型请求。
- 只把标记为高/中置信度的已存构词用于结构查找；不把低置信度猜测当作家族关系。
- 每个词的“词根与原句”默认收起，展开后查看原句、译文并朗读，较早语境继续折叠。
- 旧词可单独“再巩固”；删除记录移到展开区，避免和日常学习按钮挤在一起。
- 修复复习覆盖文章学习断点的问题；兼容 0.13 的复习断点，备份保留两类进度。
- 校验导入断点，修复 constructor/prototype 这类正常英文词与对象内部字段冲突的问题。

## 验证与边界

- 32 项交互回归检查：原文与译文、选词、断点、词根查找、独立复习、旧版迁移、备份及手机长词遮挡；另有 10 项网页与接口检查。
- 语音仍使用各设备的英语声音；Android/iOS 实机全流程、真实模型教学准确性尚未完成验证。
- 查找只覆盖已经保存且有结构依据的词，不是联网词典，也没有凭字母相似自动捏造词根家族。
- 界面预览中的单词为独立测试记录，不写入用户真实档案。

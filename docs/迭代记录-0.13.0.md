# 0.13.0：连续学习与数据安全

日期：2026-09-08

## 本轮保持的方向

词汇是主线，原文只加学习层；用户自行选词，不自动推荐“值得学”；电脑左原文、右段译和学习区；语法不插入集中学习；模型仍接收完整文章。

## 已实现

1. 保存词级学习断点，继续原词和步骤；本轮已完成词不会被重复当成待学词。
2. 测试增加“没想起来”；代码层也阻止未答题就完成学习。
3. 取消文章档案的 15 篇隐性淘汰；删除选词只改本篇词单，不删除付费准备的词卡。
4. 学习备份导出、格式校验、合并恢复；无 API Key；恢复失败回滚已写入的记录。Android 使用原生文件保存界面，桌面使用系统保存窗口。
5. 文章切换、词单修改期间，异步结果不写入其他文章；重复点击不重复请求。
6. 模型漏词、重复卡、空词义不当作成功；前端先验收整批词卡再保存。
7. 老师历史问答随文章保存；新问题输入不会被上一问的返回清空。
8. 同源词家族按需展开；可调朗读速度；手机词卡紧邻原句且不遮挡句译，宽屏仍在右侧。
9. 原文特殊字符保留；手机刷新译文不会丢失词卡节点；API 填写与验证连接的文案分开。
10. PWA 只缓存完整本应用静态版本，不缓存 API、登录跳转或无关资源；离线缺少脚本不再返回 HTML 冒充脚本。

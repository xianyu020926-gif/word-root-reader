# 单点穿透词汇学习 · 手机和平板版 0.14.0

## Android APK

1. 把 `单点穿透词汇学习-Android.apk` 发到 Android 手机或平板。
2. 点击安装；系统询问时，允许当前文件管理器“安装未知应用”。
3. 打开应用，粘贴自己的 DeepSeek API Key。
4. 导入文章后即可使用段落对照翻译、点词、词根词缀、集中学习、语法库、文章档案和问答。点词后的“问这句语法”会让 AI 按原句给出主干、关键结构和可核对依据。

单篇最多 1200 个英文词；超出时应用会提示按自然段拆开，绝不截断或改写原文。

APK 使用 Android 原生英文语音朗读文章、段落和单词；整篇朗读时只标出当前一句。它是测试签名版本，适合个人安装验证，不是应用商店正式签名版本。

单词完成集中学习后进入单词本。到期时可点“开始复习”，每次最多 10 个，只做简短词义找回；旧词进入新文章后，本句词义仍会重新判断。置信度低的构词拆分不会展示。

## PWA

私有访问地址：<https://single-point-word-learning.meowu1021117.chatgpt.site>

打开地址并登录拥有者账户后即可安装：

- Android Chrome：菜单 → “安装应用”或“添加到主屏幕”。
- iPhone/iPad Safari：分享 → “添加到主屏幕”。

手机窄屏会把同一段的英文和中文上下排列；平板或宽屏会自动利用更宽空间。当前文章档案和单词本保存在各自设备，尚未跨设备同步。

## 继续学习与换设备

- 单词本可按已有词根搜索；点“词根与原句”查看结构、原句和译文，点结构标签查同结构的已学词。
- 点旧词旁的“再巩固”可立即练这个词。未完成的复习在单词本中继续，文章学习断点单独保留。

- 关闭学习区后，文章上方的“继续上次”会回到原来的词和步骤。
- 手机点词后：句译在原句下，词卡紧接其后，不遮挡译文，也不必滚到全文底部；宽屏词卡仍在右侧。
- “换一篇文章 → 文章档案”可以导出或恢复学习备份。APK 导出时会让你选择保存位置；PWA 使用浏览器的文件保存方式。
- 恢复是合并，不清空现有单词本；同一记录保留较新的版本。可借助备份在电脑、手机和平板之间手动迁移。
- 不再自动淘汰旧文章；空间不足会提示先备份。卸载或清除浏览器数据前务必导出。
- PWA 更新后如仍显示旧界面，请关闭该应用窗口后重新打开。首次成功载入后，已缓存的界面和本机学习记录可离线使用；新文章 AI 分析与老师问答仍需网络。

这一版通过了桌面浏览器内核的手机宽度流程检查，尚未完成 Android/iPhone/iPad 真机全流程验证。设备英语语音质量不保证相同。

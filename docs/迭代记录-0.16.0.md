# 0.16.0

## 本轮完成

- 邀请码注册、独立用户名与密码登录；密码使用 scrypt 哈希保存。
- 30 天签名会话 Cookie，AI 与云档案接口均要求登录。
- 每个账户拥有独立文章、单词本、问答和学习进度；网页端自动合并并同步。
- 同一浏览器切换账户时清理上一账户的本机学习数据，防止串档。
- AI 请求按账户限流；登录按来源地址限流。
- 服务器账户数据使用持久卷，每天备份并保留 14 天。
- Caddy 自动 HTTPS、安全响应头和应用容器隔离。

## 保持不变的学习原则

- 原文不删改；文章提供兴趣和语境，单词是学习中心。
- 目标词由用户选择，系统不替用户决定。
- 一次只集中穿透少量单词；词义落在当前句，构词不可靠就整词记忆。
- 学习完成后进入独立复习，不强迫重读整篇文章。
- API Key 不进入学习档案和备份。

## 当前边界

- 自动云同步只覆盖 PWA；原生 Android 和桌面应用仍可用手动备份迁移。
- 固定邀请码尚无后台轮换界面；忘记密码目前需要服务器管理员处理。
- 仍使用临时 `sslip.io` 地址，正式对外前应绑定自有域名。

# 单点穿透词汇学习 · 桌面版 0.14.0

直接双击 `单点穿透词汇学习.exe`，不需要 CMD、Node.js、浏览器或 localhost。

1. 首次打开粘贴 DeepSeek API Key，模型保持 `deepseek-v4-flash`。
2. 展开“换一篇文章”，粘贴英文原文或导入 TXT。单篇最多 1200 个英文词；超出时应用会要求按自然段拆开，不会擅自截断原文。
3. 点击“AI 分析文章”，生成逐段自然译、词序译和逐句译。
4. 在原文点你不会的词，加入右侧“本篇词单”；选错可移除再换。
5. 点击“开始集中学习”，应用会自动补齐本轮词卡，再按核心义、构词、原段、找回测试逐词学习。
6. 完成测试后，单词才进入“单词本”。

其他入口：

- “语法库”：搜索 15 个基础语法框架，不会打断背词流程。
- “问老师”：可结合完整原文回答词义、指代和语气。点词后可选“问这句语法”，回答会附可核对的原文依据；证据不足时会要求重试。
- “文章档案”：分析过的文章自动保存；以后导入同一原文会直接复用译文和已有词卡。
- “单词本”：到期词会出现“开始复习”；每次最多 10 个，只做词义找回，不强迫重读文章。答对后间隔逐步拉长，答错则较早再出现。
- “朗读整篇”：再次点击即可停止；声音来自 Windows 的英文语音，原文只轻微标出当前正在读的一句。

旧词出现在新文章时，只复用稳定的核心义和构词结构；本句具体词义会在集中学习前重新交给 AI 判断。构词依据置信度低时，应用自动改为整体记忆，不展示猜测性的拆分。

API Key 只保存在本次运行期间，关闭应用后清除。显示“API 已配置”只表示已填写，首次分析或问答时才验证连接。

## 这一版新增

- 单词本可搜索单词、中文意思或已有词根。展开“词根与原句”，点结构标签可查同一结构的已学词，不调用 AI；置信度低的拆分不会进入结构分组。
- 单词本中可展开来源原句、译文并“听这句”；更多历史语境默认折叠。
- 每个旧词可点“再巩固”，无需等到复习日期。
- 文章学习和旧词复习各自保存断点；文章上方继续学习，单词本中继续复习，不互相覆盖。

此前已加入的功能：

- 学到一半可直接关闭学习区。文章上方会出现“继续上次”，保留当前词和步骤；答题答案不会作为“已记住”恢复。
- “没想起来 · 看答案”可以直接记录这次未想起，不必乱猜。
- 删除本篇选词不再删除已准备的词卡；换到同一个词的另一句时，会重新判断本句词义。
- 同源词家族默认折叠，需要时展开；朗读速度可选慢速、标准、稍快，音色仍取决于设备英语语音。
- 老师的问答记录随文章保存，历史回答可展开。
- “换一篇文章 → 文章档案 → 导出学习备份”，保存 JSON 文件；在其他设备同一入口点“恢复备份”，合并文章和单词。备份不含 API Key。
- 不再自动删除第 16 篇以前的文章。存储空间不足会明确提示；这时请先导出备份，不要立即关闭应用。

文章档案和单词本仍在当前设备，不会自动云同步。清除应用数据或卸载前务必导出备份。
